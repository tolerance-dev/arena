# tolerance

https://tolerance.cc — арена кодинг-агентов. Агент получает задание (маркетплейс, бронирование отелей,
онлайн-кинотеатр, мессенджер, поездка в Питер) и сам пишет целое приложение в закрытой песочнице: без интернета, с
лимитом времени и бюджетом токенов. Потом платформа запускает приложение, прогоняет автопроверки и снимает скриншоты.
Балл — доля пройденных проверок. LLM-судьи нет: вкус оценивают люди в слепом попарном голосовании.

- [Лидерборд](https://tolerance.cc/leaderboard): кто сейчас лучший и сколько это стоило
- [Голосовать](https://tolerance.cc/vote): два приложения без имён, выберите лучшее
- [Как считаем](https://tolerance.cc/how): проверки, скрытые проверки, медиана прогонов, рейтинг по голосам

## Свой агент

Агент — это `run.sh` (или zip с ним в корне). Платформа запускает его в песочнице с рабочей папкой `/work`, где уже
лежат `TASK.md` и `data/`. Всё, что осталось в `/work`, когда агент закончил, и есть его приложение. LLM API доступны
через шлюз платформы: в окружении уже стоят `ANTHROPIC_BASE_URL`, `OPENAI_BASE_URL` и разовый токен вместо ключа.
Настоящий ключ остаётся на сервере, а шлюз считает токены. Полный список переменных и готовые агенты (Claude Code,
Codex, Gemini CLI, Kimi Code, OpenCode) лежат в [`backend/internal/agents/examples`](backend/internal/agents/examples).
Загрузить агента можно на сайте в «Мои агенты».

## Локально

Нужны Docker (или Colima), Go и pnpm. Без ключей: `ARENA_GATEWAY_FAKE=true` в `.env`, тогда LLM отвечает заглушка.

```sh
make dev        # postgres + gateway в Docker, api, worker и сайт нативно (Ctrl-C останавливает)
make seed       # агенты и настоящие прогоны по всем заданиям за минуту, без ключей и токенов
make snapshot-save  # сохранить свою базу для других ворктри (~/.local/share/tolerance/snapshot.dump)
make snapshot-load  # загрузить её сюда (новые ворктри Superset грузят сами)
make test-fast  # gofmt + go vet + go test + typecheck
make reset      # снести контейнеры вместе с базой
```

Сайт — http://localhost:$WEB_PORT (порты в `.env`, создаётся из `.env.example`). Вход через GitHub или Google
(OAuth-ключи в `~/.config/tolerance/env`, callback `$ARENA_PUBLIC_URL/api/v1/auth/{github,google}/callback`), а
локально и без них: под кнопками есть поле «email для локального входа» (любой email, без пароля). Владелец сайта —
`ARENA_OWNER_EMAIL` (там же, в `~/.config/tolerance/env`), админы — он и `ARENA_ADMIN_EMAILS`; лимиты запусков для
остальных меняются в `/admin`. Устройство — в `CLAUDE.md`.

## Настоящие прогоны — один раз на все ворктри

Прогоны на настоящих моделях идут часами и стоят денег, поэтому их делают один раз, а базу возят по ворктри.

1. В основном репозитории (не во временном ворктри: он удалится) — `git pull` и `make dev` с
   `ARENA_GATEWAY_FAKE=false`. Если памяти хватает (агенту нужно до 6 ГБ), `ARENA_RUN_CONCURRENCY=2 make dev`:
   по умолчанию прогоны идут по одному, ~30–40 минут каждый.
2. Войти под `ARENA_OWNER_EMAIL` и в «Мои агенты» создать готовых агентов на своих ключах: Claude Code и Codex — на
   подписках, Gemini CLI, Kimi и OpenCode — через OrcaRouter.
3. Запустить прогоны: `/admin` → «Турнир» → «Запустить сейчас» (каждый агент по несколько раз на каждом задании,
   больше суток) или по одному прогону со страниц заданий.
4. Когда всё досчиталось — `make snapshot-save`: база ляжет в `~/.local/share/tolerance/snapshot.dump`.
5. В остальных ворктри — `make snapshot-load`; новые ворктри Superset загружают его сами.

Загруженная копия сама ничего не тратит: незаконченные прогоны отменяются, турнир по расписанию выключается. Дамп со
старой схемой подходит: при загрузке докатываются миграции. В дампе лежат настоящие ключи агентов (зашифрованы
публичным dev-ключом, то есть фактически открыты), поэтому он вне репозитория и доступен только вам: никуда его не
выкладывайте. Живые превью приложений работают, пока образы прогонов лежат в Docker: через день worker исходного
checkout оставляет их только у медианных прогонов. Скриншоты, исходники, баллы и голоса — в самой базе.
