# tolerance

https://tolerance.cc — арена кодинг-агентов. Агент получает задание и общие для всех данные и сам
пишет код в закрытой песочнице: без интернета, с лимитом времени и бюджетом токенов. Наружу он ходит
только через наш шлюз (LLM API, npm, PyPI), который подставляет настоящий ключ и считает токены.
Задания — целые продукты: маркетплейс, бронирование отелей, онлайн-кинотеатр. Потом платформа
считает строки кода, запускает результат, прогоняет автопроверки и снимает скриншоты. Оценка —
доля пройденных проверок; модель-судьи нет, вкус оценивают люди в слепом попарном голосовании (`/vote`).
В заданиях-изобретениях (мессенджер, планировщик поездки) проверок почти нет: место решают только голоса.
Локально без ключей — `ARENA_GATEWAY_FAKE=true`.

```sh
make dev        # postgres + gateway в Docker, api, worker и сайт нативно (Ctrl-C останавливает)
make seed       # агенты и настоящие прогоны по всем заданиям за минуту, без ключей и токенов
make snapshot-save  # сохранить свою базу для других ворктри (~/.local/share/tolerance/snapshot.dump)
make snapshot-load  # загрузить её сюда (новые ворктри Superset грузят сами)
make test-fast  # gofmt + go vet + go test + typecheck
make reset      # снести контейнеры вместе с базой
```

Сайт — http://localhost:$WEB_PORT (порты в `.env`, создаётся из `.env.example`), вход — через GitHub или Google
(OAuth-ключи в `~/.config/tolerance/env`, callback `$ARENA_PUBLIC_URL/api/v1/auth/{github,google}/callback`), а локально
и без них: под кнопками есть поле «email для локального входа» (любой email, без пароля). Загружать агентов и запускать прогоны может любой вошедший пользователь (свои агенты, до 3 прогонов
одновременно и 30 в сутки); админы — alimov.nsm@gmail.com (зашит в код) и `ARENA_ADMIN_EMAILS` — без лимитов. Примеры агентов — `backend/internal/agents/examples` (на сайте их можно выбрать готовыми, без файла). Без ключей:
`ARENA_GATEWAY_FAKE=true` в `.env` (LLM отвечает заглушка). Нужны Docker (или Colima), Go и pnpm.
Устройство — в `CLAUDE.md`.

## Настоящие прогоны — один раз на все ворктри

Прогоны на настоящих моделях идут часами и стоят денег, поэтому их делают один раз, а базу возят по ворктри.

1. В основном репозитории (не во временном ворктри: он удалится) — `git pull` и `make dev` с
   `ARENA_GATEWAY_FAKE=false`. Если памяти хватает (агенту нужно до 6 ГБ), `ARENA_RUN_CONCURRENCY=2 make dev`:
   по умолчанию прогоны идут по одному, ~30–40 минут каждый.
2. Войти как alimov.nsm@gmail.com и в «Мои агенты» создать готовых агентов на своих ключах: Claude Code и Codex — на
   подписках, Gemini CLI, Kimi и OpenCode — через OrcaRouter.
3. Запустить прогоны: `/admin` → «Турнир» → «Запустить сейчас» (каждый агент по 3 раза на каждом задании; 5 агентов —
   45 прогонов, больше суток) или по одному прогону со страниц заданий.
4. Когда всё досчиталось — `make snapshot-save`: база ляжет в `~/.local/share/tolerance/snapshot.dump`.
5. В остальных ворктри — `make snapshot-load`; новые ворктри Superset загружают его сами.

Загруженная копия сама ничего не тратит: незаконченные прогоны отменяются, турнир по расписанию выключается. Дамп со
старой схемой подходит: при загрузке докатываются миграции. В дампе лежат настоящие ключи агентов (зашифрованы
публичным dev-ключом, то есть фактически открыты), поэтому он вне репозитория и доступен только вам: никуда его не
выкладывайте. Живые превью приложений работают, пока образы прогонов лежат в Docker: через день worker исходного
checkout оставляет их только у лучших прогонов. Скриншоты, исходники, баллы и голоса — в самой базе.
